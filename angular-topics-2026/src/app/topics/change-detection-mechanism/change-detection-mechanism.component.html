Strategy Comparison

Default Strategy

  • Checks all components
  • Triggers on every async operation
  • Simple but can be slow

OnPush Strategy

  • Checks only when inputs change
  • Requires manual triggering
  • Fast but requires careful management

Best Practices

Use OnPush Strategically

Apply OnPush to components that don't need frequent updates

Avoid Direct DOM Manipulation

Let Angular handle DOM updates to prevent breaking change detection

Use NgZone Wisely

Run heavy computations outside Angular zone, then manually trigger change detection

Immutable Data

Use immutable operations for objects and arrays

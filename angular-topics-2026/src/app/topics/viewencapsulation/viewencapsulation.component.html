Angular View Encapsulation

What is View Encapsulation?

In Angular, View Encapsulation determines how the styles defined in a component affect the DOM. It controls whether the styles are:

  • Scoped to the component only
  • Global and affect all elements

It is useful to avoid CSS conflicts when multiple components use similar class names.

Types of View Encapsulation

Angular provides three strategies:

  • Emulated (default): Styles are scoped using _ngcontent attributes. Safe and most commonly used.
  • None: Styles are global. Component styles can affect entire app.
  • ShadowDom: Uses native Shadow DOM encapsulation. Styles are truly scoped to component.

Example: Applying View Encapsulation

In the component TypeScript file, you can define the encapsulation mode: 

import { Component, ViewEncapsulation } from '@angular/core';

@Component({
  selector: 'app-encapsulation-demo',
  templateUrl: './encapsulation-demo.component.html',
  styleUrls: ['./encapsulation-demo.component.css'],
  encapsulation: ViewEncapsulation.Emulated
})
export class EncapsulationDemoComponent { }

Change ViewEncapsulation.Emulated to None or ShadowDom to see different behaviors.

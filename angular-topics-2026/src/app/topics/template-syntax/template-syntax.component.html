Angular Template Syntax

Master the powerful syntax for building dynamic Angular templates

🎯 Introduction

Angular template syntax is a powerful set of tools that allows you to create dynamic, interactive user interfaces. It combines HTML with Angular-specific syntax to bind data, handle events, and control the DOM structure.

📝 1. Interpolation

Interpolation displays component property values in the template. It's the simplest form of data binding, using double curly braces.

Example:

<p>Welcome to {{ title }}</p>
<p>Current time: {{ currentTime | date:'short' }}</p>
<p>User: {{ user?.name }}, Age: {{ user?.age }}</p>

Output:

Welcome to {{ title }}

Current time: {{ currentTime | date:'short' }}

User: {{ user?.name }}, Age: {{ user?.age }}

🔗 2. Property Binding ([property])

Property binding sets element properties to component property values. It uses square brackets and allows one-way data flow from component to template.

Example:

<img [src]="imageUrl" [alt]="title" />
<button [disabled]="isDisabled" [innerText]="buttonText"></button>
<input [value]="name" />

Output:



🎧 3. Event Binding ((event))

Event binding listens for DOM events and calls component methods. It uses parentheses and allows one-way data flow from template to component.

Example:

<button (click)="onButtonClick()">Click me</button>
<p>Click count: {{ clickCount }}</p>

<input (input)="onInputChange($event)" placeholder="Type something" />
<p>Input value: {{ inputValue }}</p>

Output:

Click count: {{ clickCount }}

Input value: {{ inputValue }}

🔄 4. Two-Way Data Binding ([(ngModel)])

Two-way binding combines property and event binding. It uses banana-in-a-box syntax and synchronizes data between component and template.

Example:

<input [(ngModel)]="name" placeholder="Enter your name" />
<p>Hello, {{ name }}!</p>

Output:

Hello, {{ name }}!

🏗️ 5. Structural Directives

Structural directives change the DOM layout by adding, removing, or manipulating elements. They start with an asterisk (*) which is syntactic sugar for <ng-template>.

*ngIf

<div *ngIf="showDetails">
  <p>These details are visible!</p>
</div>
<button (click)="toggleDetails()">Toggle Details</button>

These details are visible!

*ngFor

<ul>
  <li *ngFor="let item of items; trackBy: trackByIndex">
    item
  </li>
</ul>
  • {{ item }}

*ngSwitch

<div [ngSwitch]="selectedItem">
  <p *ngSwitchCase="'Item 1'">First item selected</p>
  <p *ngSwitchCase="'Item 2'">Second item selected</p>
  <p *ngSwitchDefault>Other item selected</p>
</div>

<select [(ngModel)]="selectedItem">
  <option *ngFor="let item of items" [value]="item">item</option>
</select>

First item selected

Second item selected

Other item selected

🎨 6. Attribute Directives

Attribute directives change the appearance or behavior of DOM elements. They use square brackets and can be built-in or custom.

Example:

<p [class.active]="isActive">This text can be active</p>
<p [style.color]="isActive ? 'green' : 'red'">Color changes</p>
<p [attr.title]="title">Hover for title</p>

This text can be active

Color changes

Hover for title

🔧 7. Template Reference Variables (#var)

Template reference variables capture DOM elements, directives, or components for use elsewhere in the template.

Example:

<input #nameInput type="text" />
<button (click)="name = nameInput.value">Update Name</button>
<p>Name: {{ name }}</p>

Name: {{ name }}

🪈 8. Pipes (|)

Pipes transform data for display. They can be chained and accept parameters. Angular provides built-in pipes and you can create custom ones.

Example:

<p>Amount: {{ amount | currency:'USD':'symbol':'1.2-2' }}</p>
<p>Birthday: {{ birthday | date:'fullDate' }}</p>
<p>Text: {{ text | uppercase | slice:0:5 }}</p>
<p>Items: {{ items | json }}</p>

Amount: {{ amount | currency:'USD':'symbol':'1.2-2' }}

Birthday: {{ birthday | date:'fullDate' }}

Text: {{ text | uppercase | slice:0:5 }}

Items: {{ items | json }}

🛡️ 9. Safe Navigation Operator (?.)

The safe navigation operator prevents null reference errors by short-circuiting property access when the object is null or undefined.

Example:

<p>User name: {{ user?.name }}</p>
<p>User details: {{ user?.details?.address }}</p>

User name: {{ user?.name }}

User details: {{ user?.details?.address }}

❗ 10. Non-null Assertion Operator (!)

The non-null assertion operator tells TypeScript that a value is not null or undefined, useful when you're certain the value exists.

Example:

<p>Definite user: {{ user!.name }}</p>

Definite user: {{ user!.name }}

✨ Best Practices

  • Use interpolation for simple text display
  • Prefer property binding over string interpolation for element properties
  • Use two-way binding sparingly, only when necessary
  • Always use trackBy with *ngFor for better performance
  • Use safe navigation operator to prevent null reference errors
  • Keep templates clean by extracting complex logic to component methods

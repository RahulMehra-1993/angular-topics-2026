Pure and Impure pipe

What is a Pipe?

A pipe in Angular is used to transform data in templates. It can modify display format, filter data, or change text without touching the component.

Example of built-in pipes:

  • {{ 12345.6789 | number: '1.2-2' }} → Number pipe
  • {{ 'angular pipes demo' | titlecase }} → Text transformation
  • {{ 0.256 | percent: '1.0-1' }} → Percent pipe
  • {{ today | date: 'fullDate' }} → Date pipe

Pure Pipe (updates only when input reference changes)

Type in search to filter → Pure pipe updates. Click Add Fruit (Mutate Array) → Pure pipe will NOT update. Click Add Fruit (New Reference) → Pure pipe will update.

Open your console and check on clicking both the buttons. You will see the difference in execution.

Impure Pipe (updates on every change detection)

Any change, mutation, or typing in search triggers this pipe. Use sparingly for large lists to avoid performance issues.

Async Pipe

The async pipe subscribes to an Observable or Promise in the template, automatically renders the latest value, and unsubscribes when the component is destroyed.

This is very useful for fetching data from APIs or reactive streams without manually subscribing in the component.

Example with Observable:

  • Value updates every 1 second from an observable:
  • {{ randomNumber$ | async }}

Example with Promise:

  • Value resolves after 3 seconds:
  • {{ delayedMessage$ | async }}

🎯 Custom Directives in Angular

Master the art of creating reusable directive logic

🔍 What are Directives?

Directives are classes that add additional behavior to elements in your Angular applications. They are one of the core building blocks of Angular and allow you to extend HTML with custom functionality.

📦 Components

The most common type of directive. Components have templates and are the building blocks of UI.

@Component({ selector: 'app-my-component' })

🏗️ Structural Directives

Change the DOM layout by adding/removing elements. Identified by the asterisk (*) prefix.

*ngIf, *ngFor, *ngSwitch

🎨 Attribute Directives

Change the appearance or behavior of an element. Don't change the DOM structure.

ngClass, ngStyle, ngModel

⚡ Creating Custom Directives

1

Generate the Directive

ng generate directive highlight
2

Import Directive

import { HighlightDirective } from './highlight.directive';
3

Add to Declarations

@NgModule({ declarations: [HighlightDirective] })
4

Use in Template

<p appHighlight>Highlighted text</p>

A structural directive that shows content when condition is false

The *appUnless directive is the opposite of *ngIf

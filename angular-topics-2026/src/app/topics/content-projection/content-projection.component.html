📦 Content Projection in Angular

Reusing components while allowing flexible content insertion

🔍 What is Content Projection?

Content Projection is a powerful Angular feature that allows you to pass HTML content from a parent component into a child component. Instead of hardcoding content inside the child, Angular lets the parent decide what should be displayed.

Angular uses the <ng-content> directive to project external content into predefined placeholders inside a component.

🎯 Why Use Content Projection?

  • ✅ Creates highly reusable components
  • ✅ Separates layout from content
  • ✅ Avoids duplicate UI logic
  • ✅ Makes components flexible and customizable
  • ✅ Commonly used in modals, cards, tabs, and layouts

⚙️ How Content Projection Works

  1. Parent component passes HTML inside the child selector
  2. Child component defines where content should appear using <ng-content>
  3. Angular automatically inserts the parent content at runtime
